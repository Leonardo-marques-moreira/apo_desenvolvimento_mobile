# \# Paraná em Números

# 

# Aplicativo mobile em Flutter que lista as cidades mais populosas do Paraná

# com o número de habitantes e traz uma saudação personalizada.

# 

# Projeto da Atividade Prática Orientada (APO) da disciplina de

# Desenvolvimento Mobile, Análise e Desenvolvimento de Sitemas - UNIPAR EAD.

# 

# \## Telas

# 

# \- \*\*Splash:\*\* tela inicial de 3 segundos com o logo do app.

# \- \*\*Cidades:\*\* lista com as 21 cidades mais populosas, com posição e população.

# \- \*\*Saudação:\*\* o usuário digita o nome, toca em "Ok" e recebe "Olá, nome!",

# &#x20; com um botão para resetar. Valida campo vazio.

# \- \*\*Sobre:\*\* descrição do app e versão, acessada pelo menu da AppBar.

# 

# \## Tecnologias

# 

# \- Flutter e Dart

# \- Material Design

# \- Git e GitHub

# 

# \## Como executar

# 

# 1\. Instale o Flutter e o Android Studio.

# 2\. Clone o repositório:

# &#x20;  git clone https://github.com/Leonardo-marques-moreira/apo\_desenvolvimento\_mobile.git

# 3\. Na pasta do projeto, rode `flutter pub get` e depois `flutter run`.

#
